## 项目介绍

**橙橙计划**是一款接入大模型 API 的个人计划与提醒手机应用。用户只需描述目标、期限和计划要求，AI 就能将目标拆解为带日期与时间的具体任务。计划由用户审核确认后才会生效，之后可以在今日清单或日历中查看、打卡和调整。

项目坚持本地优先：目标、计划、任务及完成记录保存在手机中；API Key 使用系统安全存储单独保管，不进入业务数据库或备份文件。第一版面向个人使用，不包含注册、云同步、付费或社交功能。

## 核心功能

- **AI 生成计划**：根据目标和限制条件生成可执行任务，生成前支持补充追问。
- **人工审核确认**：计划生效前可逐项修改，也可要求 AI 调整；用户始终拥有最终决定权。
- **今日与逾期清单**：今日任务按时间排序并标注所属目标；逾期任务按目标分类展示。
- **日历与目标管理**：从日期或目标两个角度查看任务，随时修改目标和安排。
- **任务操作**：支持完成、延后、跳过、删除、重新安排，以及最近删除恢复。
- **本地系统提醒**：滚动维护近期通知，任务到期仍未完成时进行提醒。
- **目标鼓励动画**：完成阶段或目标时提供简洁的正向反馈，并尊重系统“减少动态效果”设置。
- **多模型配置**：支持 OpenAI 兼容接口和火山方舟 Ark 接口，可接入 DeepSeek、豆包等模型。
- **本地数据保护**：SQLite 持久化、关键事务备份、三份轮换恢复副本和异常恢复入口。

## 本地运行

### 环境要求

- Node.js 20 或更高版本
- pnpm
- iPhone 与 Expo Go（真机预览）

### 安装与启动

```bash
pnpm install
pnpm start
```

启动后使用 iPhone 上的 Expo Go 扫描二维码。电脑与手机需处于可互相访问的网络环境；必要时可使用 Expo tunnel。

### 质量检查

```bash
pnpm typecheck
pnpm test
```

真机功能检查可参考 [真机验收清单](./真机验收清单.md)。

## 数据与隐私

- 业务数据保存在手机应用沙盒内，关闭应用或重启手机不会清空数据。
- 关键事务完成后生成带校验值的 JSON 恢复副本，最多保留最近三份。
- API Key 使用 SecureStore 保存，不进入 SQLite、恢复副本、日志或源码。
- 数据库升级或恢复失败时保留原文件，不通过清空数据掩盖错误。
- 调用 AI 服务时，仅向用户自行配置的服务商发送生成计划所需内容。
