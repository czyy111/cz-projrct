## 本地检查

```powershell
pnpm typecheck
pnpm test
pnpm start
```

使用 Windows 随附开发环境运行时，需要先确保 Node.js 与 pnpm 可执行文件已经加入 `PATH`。项目运行数据存放在手机应用沙盒中，不写入源码目录。

## 数据保护

- 业务数据由 SQLite 持久化，关闭应用或重启手机不会主动清空。
- 关键事务成功后生成带校验值的 JSON 恢复副本，最多保留最近三份。
- API Key 将由 SecureStore 单独保存，不进入 SQLite、恢复副本或源码。
- 数据库升级或恢复失败时停止启动并保留已有文件，不通过清库掩盖错误。
