# 橙橙计划产品文档

这里保存橙橙计划从需求分析到开发实施的完整产品设计蓝本。文档按项目阶段排列，已确认的产品决定应以对应文档中的最新版本与变更记录为准。

| 阶段 | 文档 | 内容 |
| --- | --- | --- |
| 1 | [产品需求文档 PRD](./PRD.md) | 产品定位、MVP 范围、功能需求、异常处理和验收标准 |
| 2 | [信息架构](./信息架构.md) | 功能模块、页面清单、导航结构和页面关系 |
| 3 | [用户流程](./用户流程.md) | 创建目标、生成计划、审核修改、打卡和提醒流程 |
| 4 | [页面原型与排版](./页面原型.md) | 已确认页面结构、信息层级与交互规则 |
| 5 | [视觉设计](./视觉设计.md) | 品牌方向、颜色、字体、组件、动效与深色模式 |
| 6 | [技术方案](./技术方案.md) | 客户端、本地数据、密钥、通知、模型接口和测试方案 |
| 7 | [开发计划](./开发计划.md) | MVP 开发批次、完成情况、验证方式与交付要求 |

## 阅读建议

首次了解项目可依次阅读 PRD、信息架构和用户流程；参与界面实现时重点参考页面原型与视觉设计；进行工程维护时参考技术方案和开发计划。

## 文档维护规则

- 保留各文档的版本号、修改日期和变更记录。
- 新决定与旧决定冲突时，先记录冲突，再更新对应文档。
- 产品范围变化应优先更新 PRD，再同步到后续阶段文档。
- 实际代码与文档不一致时，应明确标注差异，不能静默覆盖已经确认的决定。
