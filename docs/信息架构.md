## 已确认事项

1. 应用采用“任务与目标并重”的组织方式。
2. 底部一级导航包含：今日、日历、目标、设置。
3. API 配置、通知、最近删除、数据与隐私和应用说明统一归入设置。
4. “今日”包含逾期任务和今天的任务，不包含普通未来任务。
5. 目标详情以目标概况为主节点，计划、任务和记录作为下级节点。
6. 创建目标只从“目标”一级入口发起。
7. 日历和指定日期任务归入同一个日历节点。
8. 目标入口默认显示执行中和已暂停目标；已完成和已终止目标归入历史目标。
9. 首次使用说明提供 API 配置入口，同时允许跳过；跳过后可以手工创建计划，首次使用 AI 时再次引导配置。
10. 手工新增单个任务可以从“目标任务”和“日历”发起；从日历发起时必须选择所属目标；“今日”不提供新增任务入口。

## 信息架构原则

- “今日”服务每日执行，减少用户完成任务所需的层级。
- “日历”服务未来安排和跨日期查看。
- “目标”服务目标、阶段、计划和长期习惯的整体管理。
- “设置”服务低频配置和辅助管理。
- 同一个任务可以从今日、日历或所属目标进入，但应指向同一份任务数据。
- 信息架构只确定内容归属、页面层级和跳转关系，不决定页面排版和视觉样式。

## 一级导航

### 1. 今日

核心职责：帮助用户查看和处理当前需要执行的任务。

候选下级节点：

- 逾期任务集合。
- 今日任务集合。
- 任务详情。
- 任务编辑。
- 完成、跳过、延后等任务操作。

今日不提供创建目标入口。未来任务主要通过“日历”查看。

### 2. 日历

核心职责：按日期查看过去、今天和未来的任务安排。

候选下级节点：

- 日历总览。
- 当前选中日期的任务集合，与日历总览属于同一个节点。
- 新增单个任务，创建时必须选择所属目标。
- 任务详情。
- 任务编辑。
- 时间冲突提示。

日历与日期任务不建立强制页面跳转。具体如何同时展示留到页面原型阶段确认。

### 3. 目标

核心职责：管理期限型目标、长期习惯、计划、阶段和整体进度。

候选下级节点：

- 目标列表。
- 历史目标。
- 创建目标入口，这是创建目标的唯一一级发起位置。
- 目标概况。
- 目标计划。
- 目标任务。
- 目标记录。
- AI 追问流程。
- 目标条件确认。
- 手工计划创建。
- AI 计划草稿审核。
- 计划重新生成和旧草稿恢复。
- 阶段或里程碑。
- 目标关联任务。
- 目标暂停与恢复。
- 阶段达成结果。
- 目标完成确认。

目标概况是目标详情的主节点；计划、任务和记录作为其下级节点。具体采用页内切换还是独立页面，留到页面原型阶段确认。

### 4. 设置

核心职责：管理低频配置、数据和应用说明。

候选下级节点：

- 大模型 API 配置列表。
- API 配置新增与编辑。
- 默认 API 配置。
- 通知权限与默认提醒设置。
- 最近删除。
- 数据与隐私。
- 应用说明和版本信息。

## 主要跳转关系 v0.4

### 首次使用

```text
首次使用说明
→ 可选 API 配置
→ 通知权限说明
→ 今日
```

用户跳过 API 配置后仍可进入应用。之后首次选择 AI 创建目标时，进入 API 配置引导；配置完成后返回原创建流程。

### 每日执行

```text
今日
→ 逾期任务或今日任务
→ 任务详情
→ 任务编辑或任务操作
```

### 日历查看

```text
日历
→ 选择日期并查看该日任务
→ 任务详情
→ 任务编辑或任务操作
```

日历也可以发起新增任务：

```text
日历
→ 新增任务
→ 选择所属目标并填写任务信息
→ 保存
→ 返回日历
```

### 创建目标

```text
目标
→ 创建目标
→ 选择 AI 创建或手工创建
→ 完成对应创建流程
→ 计划草稿审核
→ 用户确认
→ 目标概况
```

### 管理目标

```text
当前目标或历史目标
→ 目标概况
→ 目标计划 / 目标任务 / 目标记录
```

当前目标可以发起新增任务：

```text
目标概况
→ 目标任务
→ 新增任务
→ 自动归属当前目标
→ 保存
→ 返回目标任务
```

### 辅助设置

```text
设置
→ API 配置 / 通知设置 / 最近删除 / 数据与隐私 / 应用说明
```

## 跨入口共享节点

以下内容可以从多个一级入口进入，但不需要建立多份独立数据：

- 任务详情：今日、日历、目标均可进入。
- 任务编辑：从任务详情或相关任务集合进入。
- 目标详情：今日任务可返回所属目标，目标列表也可直接进入。
- API 调用确认：AI 追问、计划生成和重新规划时使用同一逻辑。
- 最近删除恢复：恢复后回到任务或目标的有效数据范围。
