## 已确认事项

- 产品正式名称为“橙橙计划”。
- 页面结构和排版沿用页面原型 v1.0，不在视觉阶段擅自调整。
- 需要设计产品图标方向、主色、字体、卡片、深色模式和动画风格。
- 阶段达成和目标完成需要鼓励动画。

## 视觉设计目标

- 让计划管理显得积极但不过度兴奋。
- 长时间查看任务时保持清楚、轻松。
- 逾期、错误和危险操作必须清晰，但不依靠颜色作为唯一信息。
- AI 功能与普通任务功能属于同一产品，不设计成割裂的聊天工具。
- 视觉应适合中文 iOS 手机界面。

## 整体视觉方向候选

### 方案 A：温暖清爽

- 核心气质：亲切、积极、可靠、轻量。
- 主色方向：温暖橙色，建议基准色 `#FF8A3D`。
- 背景方向：白色和轻微暖灰色。
- 字体方向：清晰的现代中文无衬线字体，字重适中。
- 卡片方向：中等圆角、轻边框、少量或无阴影。
- 图标方向：简化的橙子轮廓与完成勾结合，不使用复杂拟物细节。
- 动画方向：柔和弹性和小范围粒子，用于阶段或目标完成。
- 整体感受：像一个温暖但克制的个人计划伙伴。

优点：

- 与“橙橙计划”名称自然一致。
- 适合日常长期使用，不会过于刺激。
- 能兼顾任务效率和鼓励反馈。

缺点：

- 需要控制橙色面积，避免页面显得过暖或像促销应用。
- 浅色背景下需要认真校验橙色文字对比度。

推荐：是。

### 方案 B：明亮活力

- 核心气质：行动、效率、年轻、强反馈。
- 主色方向：高饱和亮橙，建议基准色 `#FF6B2C`。
- 辅助方向：深蓝或深灰形成强对比。
- 字体方向：标题较粗，信息层级强。
- 卡片方向：更明显的色块、圆角和状态标签。
- 图标方向：上升箭头、太阳或完成勾与橙色形状组合。
- 动画方向：更明显的弹跳、放大和庆祝粒子。
- 整体感受：强调马上行动和完成成就。

优点：

- 品牌辨识度强。
- 完成、创建和主要按钮非常醒目。

缺点：

- 长期使用可能产生视觉疲劳。
- 容易显得像效率工具或营销产品，陪伴感较弱。

### 方案 C：柔和陪伴

- 核心气质：安静、舒缓、陪伴、低压力。
- 主色方向：琥珀橙，建议基准色 `#F2A23A`。
- 背景方向：米白和浅暖灰。
- 字体方向：较柔和的圆润中文无衬线字体。
- 卡片方向：较大圆角、柔和分区和弱边界。
- 图标方向：橙子、日历或小太阳的友好组合。
- 动画方向：缓慢绽放、呼吸和轻微漂浮。
- 整体感受：降低计划压力，强调持续陪伴。

优点：

- 对习惯培养和长期计划较友好。
- 页面氛围柔和。

缺点：

- 状态和操作层级可能不如前两种锐利。
- 过度柔和时会削弱逾期提醒和效率感。

## 当前推荐

推荐方案 A“温暖清爽”。它与产品名称一致，同时比方案 B 克制、比方案 C 清晰，适合同时承载计划审核、每日打卡和鼓励反馈。

## 当前待确认

- 无阻塞待确认项。最终图标图稿、精确动画分镜和实际对比度需要在开发前按本视觉基线制作并单独验收，但不改变当前视觉方向。

## 已选视觉方向：温暖清爽

### 颜色基础

以下为视觉设计基准，技术阶段需要进行实际对比度验证：

| 用途 | 建议色值 | 说明 |
|---|---|---|
| 品牌主色 | `#FF8A3D` | 主要按钮、选中状态和品牌识别 |
| 主色按压态 | `#E96F25` | 按压或强调状态 |
| 浅色背景 | `#F8F7F4` | 页面整体暖灰背景 |
| 卡片背景 | `#FFFFFF` | 信息卡片和输入区域 |
| 主要文字 | `#262421` | 标题和正文 |
| 次要文字 | `#6F6A64` | 说明和辅助信息 |
| 分隔边框 | `#E9E5E0` | 轻边框和分隔线 |

状态色不使用主橙色强行代替：

- 成功、警告、错误和普通提示需要各自具有可区分的状态色。
- 状态必须同时使用文字或图标，不能只依赖颜色。
- 橙色文字直接放在白色背景上时需要验证对比度；不足时使用更深橙色。

### 字体基础

- 中文优先使用 iOS 系统中文字体，保持清晰和系统一致性。
- 标题使用中等或半粗字重，不使用过度粗重的促销式标题。
- 正文使用常规字重。
- 时间、进度和任务数量应保证数字易读。
- 允许用户使用系统字体缩放，重要信息不能因放大而被截断。

具体字号体系属于低风险细节，将按 iOS 常用信息层级建立，不再逐项提问。

### 卡片和控件基础

- 卡片使用中等圆角，建议基准圆角为14点。
- 以轻边框区分卡片，默认不使用明显厚重阴影。
- 主要按钮使用主橙色填充。
- 次要按钮优先使用浅色背景或边框。
- 危险操作使用独立错误色，不使用品牌橙色。
- 任务完成圆圈保持简洁，完成后同时显示勾和状态变化。
- 触控区域满足手机操作需要，不因图标视觉较小而缩小点击范围。

### 图标方向

- 应用图标采用简化橙子轮廓与完成勾结合。
- 不使用写实橙子照片或复杂拟物纹理。
- 避免同时堆叠橙子、日历、AI 星光和闹钟等多个符号。
- 主图形保持单一、易识别，并能在小尺寸下看清。
- 最终图标草案需要在技术开发前单独制作和确认，本阶段先确认方向。

### 页面视觉语气

- 今日和任务页面以清晰执行为主，控制橙色面积。
- 目标和计划页面使用轻边框卡片组织信息。
- AI 追问仍属于同一套产品视觉，不使用与全局完全不同的聊天配色。
- 逾期内容醒目但不过度警报化。
- 鼓励反馈可以比普通页面更活跃，但结束后迅速回到安静界面。

## 深色模式规则

- MVP 支持深色模式。
- 主题只跟随 iOS 系统设置，不增加应用内手动主题选择。
- 系统切换主题后，应用界面同步切换。
- 深色模式不是简单反转颜色，需要使用独立背景、卡片、文字和边框色。

深色基准建议：

| 用途 | 建议色值 | 说明 |
|---|---|---|
| 页面背景 | `#161514` | 接近暖黑，避免纯黑过强 |
| 卡片背景 | `#211F1D` | 与页面背景形成层级 |
| 主要文字 | `#F4F1ED` | 暖白正文 |
| 次要文字 | `#B8B1AA` | 辅助说明 |
| 分隔边框 | `#3A3632` | 深色模式轻边界 |
| 深色主橙 | `#FF9B58` | 比浅色模式略亮，仍需实际对比度验证 |

规则：

- 图片、插图和动画需要同时适配浅色与深色背景。
- 错误、警告和成功状态在两种主题下都必须清楚。
- 状态仍不能只依赖颜色。
- 最终色值允许在技术验证时微调，但不得改变“温暖清爽”的整体方向。

## 鼓励动画规则

### 阶段达成

- 时长约1～1.5秒。
- 使用适量橙色粒子、轻微弹性和小范围放大。
- 提供轻微触觉反馈。
- 不自动播放声音。

### 目标完成

- 时长约2～2.5秒。
- 比阶段达成具有更明显的庆祝层级，但不覆盖用户后续选择。
- 可以使用橙子轮廓、完成勾和适量庆祝粒子。
- 提供适中的触觉反馈。
- 声音默认关闭，用户可以在反馈设置中主动开启。
- 动画允许跳过。

### 可访问性

- 尊重 iOS 的“减少动态效果”设置。
- 减少动态效果开启时，改用淡入、完成勾和静态祝贺信息。
- 动画不承担唯一的信息传达职责，必须同时显示明确文字。
- 同一达成事件不自动重复播放。
